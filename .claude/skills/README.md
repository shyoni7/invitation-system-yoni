Skills in this folder are loaded automatically by Claude Code for every session on this repository.

| Skill | Source | Use for |

| `animate` | https://github.com/emilkowalski/skill (MIT) | Micro-animations: countdown, form feedback, transitions |
| `mobile-native` | https://github.com/emilkowalski/skill (MIT) | Making the invitation page feel native on phones |
| `break-ui` | https://github.com/emilkowalski/skill (MIT) | Stress-testing forms and tables with worst-case data |
| `react-best-practices` | https://github.com/vercel-labs/agent-skills (MIT) | React and Next.js performance rules |
| `composition-patterns` | https://github.com/vercel-labs/agent-skills (MIT) | Component architecture, used for the 10 invitation templates |
| `web-design-guidelines` | https://github.com/vercel-labs/agent-skills (MIT) | UI and accessibility review |
| `react-view-transitions` | https://github.com/vercel-labs/agent-skills (MIT) | Page transitions |
| `rtl-hebrew-ui` | Written for this project | Hebrew RTL + English LTR: direction, fonts, mixed text, forms, emails |

To refresh an upstream skill, clone its repo and copy the skill folder over the one here.
